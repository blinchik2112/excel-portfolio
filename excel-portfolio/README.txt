ЯК ОПУБЛІКУВАТИ БЕЗКОШТОВНО ЧЕРЕЗ GITHUB PAGES:
1. Зареєструйтеся або увійдіть на https://github.com/.
2. Створіть публічний репозиторій із назвою excel-portfolio.
3. Завантажте index.html та папку projects (зі збереженням структури).
4. Відкрийте Settings → Pages → Build and deployment.
5. У Source оберіть Deploy from a branch, гілку main і папку /(root), потім Save.
6. Дочекайтеся публікації. Адреса зазвичай буде https://ВАШ-ЛОГІН.github.io/excel-portfolio/.
7. Скопіюйте цю адресу в поле URL портфоліо LinkedIn.

ВАЖЛИВО:
- Поки сайт не опублікований, публічного URL немає.
- Репозиторій і Excel-файли стануть публічними. У файлах використані навчальні дані.
- Щоб перевірити сайт локально, відкрийте index.html подвійним кліком.
